# Дашулечке из Батуми

Одностраничный сайт-сюрприз. Пока Даша не прилетела, он показывает обратный
отсчёт. В момент прилёта (15 октября 2026, 15:00 по Батуми) сайт меняется:
другой заголовок, конфетти, салют над морем и «ты здесь».

Что внутри, сверху вниз:

1. **Первый экран.** Вечерний Батуми нарисован кодом на canvas: закат над морем,
   Алфавитная башня, колесо обозрения, огни набережной и их отражения. По небу
   летит маленький самолёт. Таймер показывает дни, часы, минуты и секунды, фраза
   под ним меняется по мере приближения.
2. **«Помнишь?»** Стопка полароидов с вашими фото. Карточку можно смахнуть
   пальцем, тап переворачивает её, на обороте подпись.
3. **«Поймай хачапури».** Мини-игра на 30 секунд. В конце открывается секретное
   послание при любом счёте.
4. **«Что мы будем делать».** Схема Батуми с точками и пунктиром маршрута.
   Тап по точке показывает план.
5. **«А теперь ты».** Три вопроса карточками и одно свободное поле. Ответы
   приходят тебе в Telegram или на почту.
6. **Письмо** и пасхалка: если тапнуть по сердечку 5 раз, откроется ещё одно
   сообщение.

Сайт статический (Vite + чистый JS), бэкенда нет.

---

## Быстрый старт

Нужен Node.js 20.19+ или 22.12+.

```bash
cd dasha-batumi
npm install
npm run dev
```

Открой адрес, который напечатает Vite (`http://localhost:5173`). Чтобы
посмотреть на телефоне, подключи его к той же Wi‑Fi сети и открой адрес из
строки `Network:`.

## Фото

1. Скопируй фото в папку **`photos/`** (jpg, png, webp). Сайт подхватывает все
   файлы сам. Каждое фото ужимается до 1100px в webp (обычно 100–250 КБ),
   поворачивается по EXIF и грузится, только когда до него дошла очередь в стопке.
2. Порядок в стопке определяется именем файла: удобно назвать `01.jpg`,
   `02.jpg`… Хочешь случайный порядок — поставь `shuffle: true` в разделе `photos`
   в `src/content.js`.
3. Подписи на обороте пишутся в **`photos/captions.json`**. Чтобы не набирать
   имена файлов руками, запусти:

   ```bash
   npm run captions
   ```

   Команда допишет в `captions.json` все новые фото с пустой подписью. Если
   подпись пустая, сайт возьмёт одну из запасных (`fallbackCaptions` в
   `content.js`).

   ```json
   {
     "01.jpg": "Тот самый закат. Посмотрим в октябре, повторится ли.",
     "02.jpg": {
       "back": "Подпись на обороте",
       "front": "Надпись под фото на лицевой стороне",
       "pos": "50% 25%"
     }
   }
   ```

   `pos` нужен, если лицо обрезается: это точка фокуса кадра (по горизонтали и
   по вертикали).

**HEIC с iPhone не поддерживается.** Такие файлы сайт пропустит и напишет об
этом в консоли. Сохрани их как JPG: на Mac через «Просмотр → Экспортировать →
JPEG», на iPhone через «Настройки → Камера → Форматы → Наиболее совместимый»
(для новых снимков) или отправь фото себе в Telegram «как фото».

Добавил фото, пока запущен `npm run dev`? Страница перезагрузится сама.

**Перед коммитом** запусти

```bash
npm run photos:clean
```

Репозиторий публичный, а фото с телефона хранят геолокацию, модель телефона и
дату съёмки. Команда удаляет все эти данные, разворачивает фото по EXIF и
уменьшает его до 2048px (для сайта хватает с запасом). Уже чистые фото она не
трогает.

## Тексты и время прилёта

Все тексты лежат в **`src/content.js`**: заголовки, фразы под таймером, точки
карты, вопросы и варианты ответов, письмо, пасхалка, подпись в подвале.

- **Время прилёта** задаётся константой в самом верху файла:

  ```js
  export const ARRIVAL = {
    date: '2026-10-15',
    time: '15:00',
    timeZone: 'Asia/Tbilisi', // Батуми, UTC+4
  };
  ```

  Это местное время Батуми. Таймер сам пересчитает его для любого часового
  пояса. Если у Даши на телефоне другой пояс, под датой появится строка «у тебя
  в этот момент будет 14:00».
- Блок `arrived: { … }` внутри раздела содержит тексты «после прилёта». Сайт
  переключится на них сам.
- Строки с пометкой **«ПРОВЕРЬ»** что-то обещают (сюрприз в первый вечер,
  конкретное место). Убедись, что это правда, или перепиши.
- `meta.title` и `meta.description` — то, что будет видно в превью ссылки в
  мессенджере.
- Точки карты: `x` от 0 до 100 (слева направо), `y` от 0 до 130 (сверху вниз),
  `label` — с какой стороны подпись (`right`, `left`, `top`, `bottom`).

## Проверить заранее

Добавь к адресу сайта:

| Адрес | Что покажет |
| --- | --- |
| `?preview=arrived` | Сразу состояние «ты здесь» с конфетти и салютом |
| `?preview=20` | Таймер на 20 секунд: можно увидеть сам момент перехода |
| `?preview=3600` | Будто остался час: проверить фразу под таймером |

Работает и локально, и на задеплоенном сайте. Даше отправляй ссылку **без**
этих параметров.

Сайт запоминает отправленные ответы и открытый секрет игры в браузере. Чтобы
пройти всё как в первый раз, открой сайт во вкладке инкогнито.

## Ответы в Telegram или на почту

Скопируй `.env.example` в `.env` и заполни **один** из вариантов. Если
заполнены оба, используется Telegram. После правки `.env` перезапусти
`npm run dev` (или пересобери сайт перед деплоем).

### Вариант 1: Telegram-бот (рекомендую, ответы приходят мгновенно)

1. Напиши [@BotFather](https://t.me/BotFather) команду `/newbot`, придумай имя и
   username. В ответ придёт токен вида `7234567890:AAH…` — это
   `VITE_TELEGRAM_BOT_TOKEN`.
2. Найди своего нового бота и нажми **Start** (или отправь `/start`). Без этого
   бот не сможет тебе писать.
3. Открой в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди
   `"chat":{"id":123456789`. Это число и есть `VITE_TELEGRAM_CHAT_ID`.
4. Впиши оба значения в `.env`:

   ```
   VITE_TELEGRAM_BOT_TOKEN=7234567890:AAH...
   VITE_TELEGRAM_CHAT_ID=123456789
   ```

> ⚠️ У статического сайта нет сервера, поэтому токен бота попадает в код
> страницы. Любой, кто откроет исходник, сможет писать от имени этого бота.
> Поэтому заведи **отдельного бота только для этого сайта**, а после поездки
> отзови токен: @BotFather → `/revoke` (или `/deletebot`).

### Вариант 2: Formspree (письмо на почту)

1. Зарегистрируйся на [formspree.io](https://formspree.io) и создай форму
   (**New Form**) на свою почту.
2. Адрес формы выглядит как `https://formspree.io/f/xyzabcde`. Последняя часть
   (`xyzabcde`) — это `VITE_FORMSPREE_ID`.
3. Один раз отправь ответы сам: Formspree может попросить подтвердить почту
   перед первым письмом.

ID формы Formspree и так предназначен для публичных сайтов, светить его не
страшно.

### Если ключей нет

Кнопка «Отправить Ашоту» откроет системное меню «Поделиться», и Даша перешлёт
ответы в любой мессенджер. Если меню недоступно, ответы скопируются в буфер. Та
же кнопка появляется, если отправка не удалась (например, пропал интернет).

## Музыка (по желанию)

Положи mp3 в `public/` (например, `public/song.mp3`) и впиши в
`src/content.js`:

```js
export const music = { src: 'song.mp3', … };
```

Справа внизу появится круглая кнопка. Музыка включается только по нажатию,
сама никогда.

## Картинка в превью ссылки

В `public/og.jpg` уже лежит картинка 1200×630 с вечерним Батуми и надписью.
Чтобы Telegram её показал, нужен полный адрес сайта: после первого деплоя
впиши его в `.env`

```
VITE_SITE_URL=https://твой-адрес.vercel.app
```

и задеплой ещё раз. Telegram кеширует превью. Если ссылку уже отправлял до
этого, перешли её боту [@WebpageBot](https://t.me/WebpageBot), и он обновит
превью.

## Деплой

### Vercel (рекомендую)

```bash
npm run deploy:vercel
```

Команда соберёт сайт у тебя на компьютере (сожмёт фото, вошьёт ключи из
`.env`) и отправит на Vercel **только готовую папку `dist/`**. Оригиналы фото и
`.env` никуда не загружаются, это задано в `.vercelignore`.

В первый раз Vercel попросит войти (откроется браузер) и задаст несколько
вопросов. Везде подходит ответ по умолчанию, имя проекта придумай любое
(например, `dasha`). В конце будет строка `Production: https://….vercel.app` —
это ссылка для Даши.

Обновить сайт после правок можно той же командой.

### GitHub Pages

```bash
npm run deploy:gh
```

Команда соберёт сайт и запушит его в ветку `gh-pages` этого репозитория. Один
раз включи Pages: GitHub → репозиторий → **Settings → Pages → Build and
deployment → Deploy from a branch → `gh-pages` / `(root)`**. Через минуту сайт
появится по адресу `https://ashotmargaryan12.github.io/veles-11/`.

> ⚠️ Репозиторий публичный. Ветка `gh-pages` с собранным сайтом (сжатые фото,
> письмо) будет лежать в нём в открытом виде. У Vercel такой проблемы нет.

## Приватность

- Фото лежат в репозитории, и репозиторий **публичный**: их видит любой, кто
  туда зайдёт. Геолокация и другие EXIF-данные удаляются командой
  `npm run photos:clean`, но сами фото остаются открытыми.
- `src/content.js` (письмо и все тексты) тоже в git.
- `.env` с ключами в git не попадает.
- Захочешь скрыть: GitHub → Settings → General → Danger Zone → Change
  visibility → Private.
- Сам сайт открыт всем, у кого есть ссылка, но поисковики его не индексируют
  (`noindex`).

## Как устроено

```
dasha-batumi/
├─ index.html            разметка секций
├─ photos/               фото + captions.json
├─ public/               favicon, картинка превью, сюда же музыка
├─ src/
│  ├─ content.js         ВСЕ тексты, время прилёта, точки карты, вопросы
│  ├─ main.js            точка входа
│  ├─ styles.css         стили (палитра и шрифты в самом верху)
│  ├─ lib/               время и часовые пояса, конфетти, отправка ответов…
│  └─ sections/          первый экран и небо, полароиды, игра, карта, вопросы, письмо
├─ plugins/photos.js     сбор и сжатие фото (sharp)
├─ scripts/              npm run captions, npm run photos:clean
└─ vercel.json           Vercel раздаёт готовый dist/
```

- **Палитра:** глубокий синий, закатное море, тёплый песок и один яркий акцент
  (шафрановый, как огни набережной).
- **Шрифты:** Caveat (рукописный, для заголовков, подписей и письма) и Manrope
  (основной текст и цифры таймера). Оба с кириллицей, из Google Fonts.
- **Телефон:** сайт рассчитан на ширину от 375px, всё управляется пальцем, без
  наведения мышью. Анимации неба и игры ставятся на паузу, когда их не видно.
- **prefers-reduced-motion:** если в системе отключена анимация, небо рисуется
  одним неподвижным кадром, без конфетти и плавных появлений.

### Почему игра про хачапури

Было три идеи:

1. **«Поймай хачапури».** Живая игра на 30 секунд, управляется одним пальцем.
   В ней есть шутки про Батуми (тучи — это батумский дождь), и она не повторяет
   блок с фото.
2. **Пазл из фото.** На телефоне быстро утомляет, и за 30–60 секунд его
   сложно собрать.
3. **«Найди пару» из ваших фото.** Милая, но спокойная, и это уже третий
   блок с теми же фотографиями.

Выбран первый вариант. Чтобы не было обидно, послание открывается при любом
счёте, а цель (15 очков) только для азарта.
